# DevOps Lab: System Analysis & Python Packaging
 
Цей проєкт містить результати виконання лабораторної роботи з аналізу системних ресурсів Linux та пакування ПЗ.
Пакет `my_devops_pkg` надає базову функцію `hello()`, яка демонструє успішну ініціалізацію модулів та роботу в ізольованих середовищах.
 
## Встановлення
Для встановлення пакета з локального репозиторію `devpi` виконайте:
```bash
pip install --index-url http://localhost:3141/devops/dev/+simple/ my_devops_pkg
```
