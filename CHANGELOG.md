# Changelog
 
## [0.1.0] - 2026-10-27
 
### Added
- Базова структура пакета за стандартом PEP 517/621 (`src-layout`).
- Модуль `my_devops_pkg` із функцією `hello()`.
- Конфігурація збірки `pyproject.toml` на базі `setuptools.build_meta`.
- Успішна збірка бінарного пакета wheel (`.whl`) та вихідного архіву (`sdist`).
- Інтеграція та публікація в локальний репозиторій `devpi`.
 
### Fixed
- Початкова стабілізація структури імпортів для ізольованого середовища.
 
### Security
- Забезпечено безпечну ізоляцію середовища розгортання через `python3-venv`.

## Навіщо Changelog важливий у DevOps-процесі?
 
1. **Автоматизація CI/CD та релізів:** Changelog дозволяє інструментам автоматизації (наприклад, semantic-release) автоматично формувати Release Notes, проставляти git-теги та оновлювати версії артефактів без участі людини.
2. **Прозорість розгортання та швидкий Rollback:** У разі виникнення інциденту на продакшені DevOps-інженер може за журналом змін миттєво визначити, які критичні виправлення або ламаючі зміни (Breaking Changes) приніс деплой, що скорочує час відновлення системи (MTTR).
3. **Координація між Dev, Ops та QA:** Забезпечує єдине джерело правди про стан продукту між розробниками, інженерами експлуатації та тестувальниками, усуваючи необхідність вручну вичитувати сотні git-коммітів.
